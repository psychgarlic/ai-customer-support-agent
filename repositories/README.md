# Репозитории

Этот модуль содержит интерфейсы для работы с данными (к��иенты, заказы, обращения).

## Архитектура

```
SupportService (бизнес-логика)
        ↓
    Repository Interface (ABC)
        ↓
    InMemory Repository (v1.0 — демо)
        ↓
    PostgreSQL Repository (v2.0 — будущее)
```

## Почему интерфейсы?

Интерфейсы (ABC) позволяют заменить реализацию хранения данных без изменения
бизнес-логики AI-агента. В версии 2.0 мы добавим `PostgreSQLCustomerRepo`,
`PostgreSQLOrderRepo` и т.д., а `SupportService` продолжит работать с теми же
интерфейсами.

## Безопасность данных

Нельзя предоставлять информацию о чужих заказах только по email или номеру заказа.
Всегда проверяйте принадлежность заказа клиенту (customer_id).
